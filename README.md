# 🤖 AI Question Answer

An AI-powered Question Answer application built using Streamlit and Hugging Face.

## Live Demo

 [Try the AI Question Answer App](https://huggingfacemodelapp-ccxygahsyeuxg56c52s8t3.streamlit.app/)

## Technologies Used

- Python
- Streamlit
- Hugging Face
- Qwen3-4B-Thinking-2507

## Features

- Ask questions in natural language
- AI-generated answers
- Simple and colorful interface
- Powered by Hugging Face Inference API

## How it works

1. Open the application.
2. Enter a question.
3. Click **Get Answer**.
4. The question is sent to the Hugging Face AI model.
5. The AI-generated answer is displayed on the screen.
